### 💡 The Evolution: Engineering Maturity

"ToTask" represents my journey from basic CRUD app to a **production-grade application** with professional tooling, testing, and deployment practices:

#### 1. From Functional to Professional Design

> **Before:** Standard UI with basic interactions. <br> > **After:** ✨ **Glassmorphism + Grid Pattern Design**. Implemented custom CSS animations, interactive hover states with glow effects, checkbox SVG components, and cohesive design system.

#### 2. From Open Data to Secure Multi-Tenant Architecture

> **Before:** All tasks visible to everyone, no authentication. <br> > **After:** 🔒 **JWT Authentication + Row-Level Security**. Built secure backend with bcrypt password hashing, token-based auth, and strict data isolation per user.

#### 3. From JavaScript to TypeScript

> **Before:** Loose typing, runtime errors, difficult refactoring. <br> > **After:** 🛡️ **Full Type Safety**. Migrated entire frontend to TypeScript with strict mode, custom types, and interface-driven development.

#### 4. From "Works on My Machine" to Containerized Development

> **Before:** Manual PostgreSQL setup, inconsistent environments. <br> > **After:** 🐳 **Docker Compose Setup**. One-command database spin-up with pgAdmin, volume persistence, and health checks. Team-ready development environment.

#### 5. From "Hope It Works" to Test-Driven Confidence

> **Before:** Manual testing, fear of refactoring. <br> > **After:** 🧪 **Comprehensive Test Suite**. Unit tests (validators), integration tests (API endpoints), and proper test structure with Vitest. All tests passing.

#### 6. From Manual Deploys to Dual-Environment Architecture

> **Before:** Single-server deployment. <br> > **After:** ⚡ **Separated Concerns**. Frontend on Vercel (CDN, instant builds), Backend on Render (PostgreSQL managed), environment variables managed per service.

#### 7. From Lost Passwords to Complete Auth Flow

> **Before:** No password recovery. <br> > **After:** 📧 **Forgot Password System**. Email integration with Nodemailer, JWT token expiration, dev mode (console links), production mode (SMTP), and secure reset flow.

### 📦 How to Run Locally

**Prerequisites:**

- Node.js 18+
- Docker Desktop
- Git

**1. Clone & Install**

```bash
git clone https://github.com/RafalauriSantos/todo-fullstack-sqlite.git
cd todo-fullstack-sqlite
npm install
cd client && npm install && cd ..
```

**2. Start Database**

```bash
docker-compose up -d
# PostgreSQL: localhost:5432
# pgAdmin: http://localhost:5050 (admin@totask.com / admin)
```

**3. Configure Environment**

```bash
cp .env.example .env
# DATABASE_URL already configured for Docker
```

**4. Run Development Server**

```bash
npm run dev
# Frontend: http://localhost:5173
# Backend: http://localhost:3000
```

**5. Run Tests**

```bash
npm test
# Or watch mode: npm test -- --watch
```

**See [SETUP.md](./SETUP.md) for complete documentation.**
